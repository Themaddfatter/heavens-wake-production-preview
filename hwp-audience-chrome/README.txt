HWP Audience Fullscreen for Chrome

1. Unzip this folder.
2. In Chrome open chrome://extensions and turn on Developer mode.
3. Click Load unpacked and select the folder containing manifest.json.
4. Reload https://production.sioncdo.com.
5. Turn Audience on using the normal HWP button. The existing operator tab stays open. No native HWP program is launched.

This extension is limited to the HWP website. It uses Chrome's windows API to create and fullscreen the separate Audience browser window. Remove it at chrome://extensions to revoke access.
