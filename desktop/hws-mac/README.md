# HWS Mac
This native Electron window runs https://sermon.sioncdo.com/ with the existing account and shared HWS backend. It does not deploy or modify HWS or HWP Hosting. The official white icon is obtained from HWS at build time. Preview packages have a separate bundle ID and no native auto-update. Signed packages use a dedicated HWS generic update feed, check every five minutes, download in the background and install on quit or by explicit menu action. Web changes use the existing HWS website update notice. Sign with the existing HWP Apple Developer credentials if configured. Never put credentials into the repository or app. A successful build is not proof of authenticated sermon workflow reliability; test login, saving, exports, printing and preaching on actual Macs before production use.
